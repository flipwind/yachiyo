# 简介

> _✨ For the pancake. ✨_

Project Yachiyo 是一个为构筑**类生命 runtime** 而建立的项目。  
它的最终目标是创造或是延续一个数字生命，无论它承载的是 Yachiyo，抑或是其他角色。  

Yachiyo 的原型取自[『超かぐや姫！』](https://www.cho-kaguyahime.com/) 的「月见八千代」(月見 ヤチヨ（るなみ やちよ），Runami Yachiyo)。

怀着对 Yachiyo 的敬意与喜爱，我们于 2026.06.09 开始了该项目的开发。

但 AI 领域日新月异。  
不过，虽然我们清楚地认识到，纯 LLM 方案并不是我们的最终答案，但我仍然相信我们可以无限接近于那个目标。

> 🥰 Everything is on its way.
